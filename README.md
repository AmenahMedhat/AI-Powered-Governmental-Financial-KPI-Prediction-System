AI-Powered Governmental Financial KPI Prediction System
A collaborative project presented by Nile University for the Ministry of Finance (Egypt).

📌 Project Overview
This project introduces an AI-powered system designed to support financial forecasting and planning. By leveraging historical data and economic factors, the system utilizes Machine Learning for financial forecasting and Large Language Models (LLMs) for economic reasoning to generate professional Arabic reports.

🚩 Problem Statement
The current approach to monitoring financial performance faces several bottlenecks:

Manual Analysis: Reliance on multiple data sources and manual analysis.

High Manpower Dependency: Significant effort is required to write analytical reports manually.

Lack of Automated Insights: There is a lack of automated explanations connecting economic factors to changes in KPIs.

Forecasting Limitations: There is a limited ability to accurately forecast fiscal KPIs.

💡 Proposed Solution
We developed an AI system that combines quantitative forecasting with qualitative reasoning:

Forecasting: Uses historical data and economic factors to predict financial trends.

LLM Integration: Generates professional Arabic reports with human-like interpretation and reasoning.


Automation: significantly reduces manual workload and provides faster, more reliable decision-making capabilities.

⚙️ System Workflow
The system follows a structured pipeline:

Simulate Results: Run simulations based on input data.

Report Generator: Create visual dashboards and textual reports.

Dashboarding: Display KPIs and Influencing Factors.

LLM-Based Analysis Module: Analyze simulated scenarios.

Interactive Discussion: Discuss results with the LLM for deeper insights.

📊 Key Metrics & Factors
The model focuses on the relationship between economic factors and core financial indicators.

Core KPIs (Target Variables)

Fiscal Deficit: (العجز المالي).

Revenue Growth: (نمو الإيرادات).

Public Debt: (الدين العام).

Debt Service Ratio: (نسبة خدمة الدين).

Influencing Economic Factors (Features)

Tax Revenues: (الايرادات الضريبيه).

Inflation Rate: (معدل التضخم).

Government Spending: (الاتفاق الحكومي).

Interest Rates: (اسعار الفائدة).

🚧 Challenges
The project addresses several technical and data-related challenges:
Heterogeneous Data Sources: Handling different formats, frequencies, and definitions.

Data Availability: Dealing with limited or incomplete data.

Data Quality: Managing missing values and unstructured reports.

Resource Constraints: Operating within limited computational resources.
